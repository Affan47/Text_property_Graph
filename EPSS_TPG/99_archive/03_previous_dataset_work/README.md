# Previous Dataset Work

This archive separates analyses of the retired datasets from the paper-revision dataset. It was created on 18 September 2026 before removing the old local datasets, graph caches, checkpoints and run outputs.

The documents retain their historical claims; they do not describe or validate the new dataset. Dataset paths, output paths and commands quoted inside them may no longer exist. Scripts in this archive are reference material, not current experiment entry points.

- `01_documentation/`: previous dataset reports, experiment reports and dataset/result manuscripts.
- `02_dataset_analysis/`: previous dataset profiles and analysis artifacts.
- `03_submodule_analysis/`: the three previously untracked analysis folders rescued from the old submodule checkout.
- `04_workflows/`: scripts tied to the retired experiment matrix.
- `05_audit/`: file inventories and cleanup records, without dataset contents or checkpoints.

Generic TPG source code, illustrative graphs and the document application are not retired by this cleanup. The new source data belongs to the `SummTPGVul` submodule on `tpg-paper-revision`; it must not be copied into the parent repository.

Deleting this archive later will also delete the only local copies of any previously untracked analysis work stored here. Review its contents before doing so.
