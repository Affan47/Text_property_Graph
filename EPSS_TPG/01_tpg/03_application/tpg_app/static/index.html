ℹ What happens when I ingest?
  1. Extract — the right reader per format (pdfplumber for PDF, python-docx for Word, BeautifulSoup for HTML…) pulls clean text with page/section context.
  2. Chunk — text is split into paragraph-sized passages on sentence boundaries (≤1200 chars) so each passage is a coherent graph unit.
  3. TPG parse — spaCy builds the linguistic graph (like a Code Property Graph for text: containment ≈ AST, token flow ≈ CFG, coreference ≈ data-flow), then the selected domain's rules add typed entities (CVE_ID DRUG …) and relations (AFFECTS TREATS …).
  4. Store — passages, entities, relations and the full per-passage graph (GraphSON) land in SQLite with a BM25 full-text index. Re-ingesting the same source is skipped.

Ask — query the knowledge graph in natural language

Your question is itself parsed into a TPG; its entities and predicates are matched against the graph, fused with BM25 full-text scoring, and the best passages come back ranked with their matched entities.
