# Current Project Status

The TPG engine and GNN implementation remain in place. On 18 September 2026 the project retired its earlier local training data and experiment artifacts and selected `tpg-paper-revision` in the existing `SummTPGVul` submodule.

1. Read [the current dataset specification](../03_datasets/00_README.md).
2. Follow [the implementation reading order](02_CODE_READING_ORDER.md).
3. Check [the experiment status](../04_experiments/00_README.md).
4. Use [the transition commands](../07_maintenance/04_DATASET_TRANSITION.md).

The replacement files were checked for record counts, unique CVEs, field presence and catalogue membership. This is not a full scientific audit of their collection process or a validation of a new learning task. No new model has been trained.

The previous investigation is preserved in [the historical findings](../../99_archive/03_previous_dataset_work/01_documentation/01_start_here/01_PROJECT_SCHEMA_AND_FINDINGS.md). Its metrics and dataset-specific conclusions do not describe the new files.
